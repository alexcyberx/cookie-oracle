# Web Flow: Cookie-Oracle Dashboard

## Navigation Map
1. Home Page (/)
 - Upload cookie/file button
 - Paste cookie textarea
 - Example cookies list
 - CTA: "Analyze Now"

2. Analysis Results (/result/:id)
 - Tabs: Summary | Full Report | Exploitation Matrix | Timeline
 - Download buttons: JSON, CSV, XML, HTML, Markdown
 - Re-analyze option

3. Past Reports (/history)
 - List of previous analyses
 - Filter by platform, date, risk score
 - Delete individual entries

4. Settings (/settings)
 - Toggle verbose mode
 - Configure custom domains/threat feeds
 - Proxy settings
